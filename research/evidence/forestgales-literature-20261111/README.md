# Evidence: ForestGALES literature research, 11.11.2026

Tasks: AS-11, boundaries AS-10 and AS-13. Main synthesis:
`research/FORESTGALES_LITERATURE_AND_CORE.md`.

These files record source access, actual reading scope, pinned public-code
metadata and local research-copy hashes. They do not record execution of
ForestGALES/fgr, a numerical port, phone tests or field validation.

- `core-sources.json`: six mechanics publications, read status, PDF locators,
  local-copy hashes. Its local paths refer to `output/forestgales-literature/core`.
- `applications-reading-scope.json`: six application/sensitivity publications;
  three were read only as abstracts/previews. Validation units stay explicit.
- `thesis-reading-scope.json`: selected sections and three visually inspected
  pages of Locatelli2016, not a cover-to-cover reading.
- `software-access.json`: official availability, licences, no public API found,
  and limits of the static source inspection. The current official delivery
  was not obtained. Licence-repository v1.0 is its own description, not proof
  of the package currently emailed by its owner.
- `public-source-checksums.json`: 34 read-only downloaded files from the pinned
  public fgr snapshot, including 29 R files. No source copied into Git.
- `research-audit.json`: performed/not-performed scope and independent review.
- `checksums.json`: SHA256 of evidence files, excluding itself. `.gitattributes`
  preserves bytes to keep the checksums identical in Git.

All full papers, complete local reading notes, page images and public source
copies remain in local output. No proprietary binaries, private paths,
credentials, user records or full copyrighted texts are included here.

The work is documentary. Source-file integrity and review checks are not
scientific validation, software execution or permission to integrate the code.

# Инструкции проекта ArborScan

Перед любой работой прочитайте [единый план проекта](deploy-vps/ARBORSCAN_MASTER_PLAN.md).
Укажите ID текущей задачи и учитывайте её критерии завершения. План не даёт автоматического разрешения выполнять остальные этапы или менять production.

После работы обновляйте в плане статусы, доказательства, ограничения и журнал изменений для затронутых ID, сохраняя остальные разделы и инструкции. Разделяйте автоматические проверки, результаты пользователя и экспериментальную валидацию. Не отмечайте частично выполненное как завершённое; статус «принято» требует подтверждения пользователя.

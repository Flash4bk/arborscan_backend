## Координаты, версии и хранение

- Все photo-точки: `normalized_oriented_image`, [0,1], uncropped оригинал
  после EXIF-orientation; метрические векторы используют реальную W/H исходника.
  Zoom/pan относится только к отображению и не входит в масштаб. PDF наносит
  именно сохранённые точки на ориентированное изображение; легенда явно
  помечает округление координат, JSON хранит исходную точность.
- Reference v1 читается прежним методом; optional v2-показатели не выдумываются.
  Серверные capabilities сообщают `reference_versions:[1,2]` и `geometry_version:2`.
  Новый клиент отказывается отправлять v2 на старый API с понятным сообщением и
  сохранением локального черновика. Схема/SQL этим исправлением не меняется.
- Локальный reference/неотправленный отчёт живёт в каталоге владельца только
  на устройстве: переживает force-stop и возвращение того же аккаунта; не
  переживает удаление приложения/очистку данных и не переносится на другой телефон.
  Явно сохранённая серверная версия содержит исходные байты и SHA, snapshot,
  UUID, родителя и владельца; открывается без нового inference/пересчёта.
- Изменение reference создаёт новую версию; старые snapshots не изменяются.
  AR остаётся независимым измерением; SHA и подтверждение связывают запись с фото,
  но не доказывают физическое совпадение объекта. β, обучение и решения масок
  не изменяются правкой геометрии.

## Конкретные исправления текущего пакета

1. `unified_analysis_report_page.dart` ранее показывал «DBH подтверждён» для
   исторического `standard=dbh_1_3m`, а остальным записям предлагал проверку
   только уровня 1,30 м. Теперь старая метка явно историческая, полевой протокол
   не подтверждается; у обычного диаметра перечислены необходимые условия.
   Фактический сохранённый уровень сечения выводится отдельно.
2. Та же страница передавала `GeometryReport(data:null)` даже при сохранённой
   geometry. Теперь передаёт frozen map выбранной версии; отсутствующие значения
   остаются недоступными. Расчёт новых метрик при открытии не выполняется.
3. `UnifiedMetric` раньше принимал строковые NaN/Infinity, а `GeometryReport`
   мог печатать NaN как физическую величину. Неконечные числа теперь недоступны;
   нулевой угол остаётся допустимым. PDF уже имел проверку конечности.

Формулы reference/AR, точки, API и persisted formats этими исправлениями не менялись.

## Выполненные текущие проверки

Среда: Windows, Flutter test; не S24 и не Android-системный диалог.

```powershell
flutter test --no-pub test/geometry_semantics_integration_test.dart `
  test/reference_measurement_test.dart test/reference_workflow_test.dart `
  test/report_history_test.dart test/report_export_test.dart --reporter expanded
```

**28 passed, 0 failed**, 14 с. Из них 5 новых регрессионных тестов проверяют
историческую семантику DBH, уровень 1,3 без сертификации, frozen geometry,
неконечные числа/нулевой угол и реальные PDF обеих восстановленных EXIF-версий.
Существующий workflow проходит EXIF-фото → все отрезки → сохранение →
пересоздание экрана/хранилища → 1 м/100 см → масштаб 2 → пересчёт с сохранением оси.
История проверяет UUID/родителя/неопределённый ответ/конфликт/смену аккаунта
на тестовом хранилище и MockClient; это не выполненная production-миграция.
Полный итоговый suite, analyzer и Android-checks отражаются в RELEASE_INTEGRATION.md
по фактическому результату root-агента.

Текущие PDF — отдельные синтетические fixtures, созданные настоящим Flutter
`buildReportPdf`: [geometry-v1](geometry-geometry-v1.pdf) и
[geometry-v2](geometry-geometry-v2.pdf). **2 файла, 8 страниц A4** перечитаны pypdf,
отрендерены Poppler и каждая страница просмотрена агентом. Сверены все числа,
единицы, версии, EXIF-ориентация 100×200, семь линий/легенда; обрезаний и наложений
не найдено. Доказательство: [geometry-pdf-checks.json](geometry-pdf-checks.json),
репрезентативные render-страницы 2/3 сохранены рядом. Это проверка реальных файлов
на Windows; экспорт через SAF/Share/S24/AVD учитывается отдельно.

Новая пользовательская приёмка и экспериментальная валидация этим аудитом
не заявлены. Остаток AS-08 — полевые входы и AS-13; формальные замены DBH,
3D-наклона и пористости не добавлялись.

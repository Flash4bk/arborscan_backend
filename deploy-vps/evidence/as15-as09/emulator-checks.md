## Реально пройдено через интерфейс

1. Регистрация, системная галерея, выбор явно синтетической картинки `DEMO AS-12`, анализ, сохранение отчёта. На синтетическом рисунке анализ корректно показал «Дерево не найдено» и не создал фиктивную маску; это проверка сценария и честного отсутствия результата, не качества сегментации.
2. Явное создание нового восьмиточечного контура, замыкание, два подтверждения, сохранение и отправка на проверку. Статус — «отправлен на проверку».
3. История после force-stop и запуска: серверный отчёт доступен и открывается. Исходный отчёт без GPS показывает доступное сообщение и действие добавления точки.
4. В исходном серверном отчёте выбрана вручную тестовая точка 50.3, 10.3; сохранена отдельная дочерняя версия. История показывает обе версии. Исходная версия после перезапуска по-прежнему без GPS.
5. Автор обновил контур после отказа администратора: увидел «отклонён» и причину `DEMO AS09 UI: refine treetop`. В редакторе восстановлены восемь точек, верхушка перетащена, создана дочерняя ревизия и повторно отправлена.
6. Второй AVD вошёл через UI и загрузил обе серверные версии. Новая версия показывает точные 50.300000,10.300000 и ручное происхождение точки; список карты сохраняет отдельные версии и настоящие счётчики 1 с точкой / 1 без точки.
7. На втором AVD отключены только его Wi-Fi/data; Android connectivity подтвердил `Active default network: none`. После force-stop и нового запуска карта открывает сохранённый список, а выбранная версия — фото и «Локальная копия серверной версии · без сети». После проверки сеть восстановлена.
8. На втором AVD системный запрос GPS отклонён через `Don't allow`. Приложение показывает «Разрешение на геолокацию не выдано.»; прежняя ручная точка сохраняется, интерфейс доступен.
9. После принятия администратором конкретной ревизии 2 автор обновил деталь и увидел «маска принята». Изменение создало ревизию 3 с parent принятой ревизии, статусом draft и отдельной кнопкой «Отправить на проверку». Новое решение для ревизии 3 не принималось.
10. Второй AVD +9 с font_scale2.0: регистрация сверху/снизу/при клавиатуре и главная проверены визуально. «Регистрация» и «Вход» переносятся на разные строки; «Создать профиль» доступна над клавиатурой, все действия главной доступны прокруткой. Вышел лишь из собственного нового тестового аккаунта этого AVD; S24 не затронут. font_scale восстановлен1.0.
11. Первый AVD: три страницы справки пройдены. Действующий профиль раскрывает связь с разработчиком и вызывает Gmail first-run через mailto; отмена двумя Back возвращает приложение. Письмо не отправлено, аккаунт Gmail не добавлялся. Legacy FeedbackPage без маршрута не считалась проверенным активным экраном.
12. На синтетической картинке выполнен весь UI известного объекта: ввод1м, явное подтверждение общей плоскости, три отрезка (эталон/дерево/крона), четырёхточечный контур эталона, результат4.77м/2.06м, локальное сохранение и «Сохранено в аккаунте». После обновления до +10/холодного запуска локальная история открыла прежнюю разметку,1м и те же4.77м/2.06м. Это тест интерфейса/хранения, не полевая точность.
13. На +10 список контуров показывает короткие даты и честный неизвестный статус, деталь показывает настоящий draft. Редактор восстановил8точек, оригинальное фото видно вне маски и под полупрозрачной заливкой. Быстрый preview показывает фото+маску; закрытие возвращает редактор без изменения. ## Отдельные HTTPS-проверки (не UI)

Независимый HTTPS-клиент вошёл лишь новым синтетическим логином. Получил две точные версии, проверил одинаковый image_sha256 и неизменность report; GPS добавлен только дочерней версии. Это не подтверждение физической точности и не проверка обучения.

## Найденные дефекты

- Список сохранённых контуров старого API не возвращает статус; APK 8 показывал ошибочный «черновик», тогда как деталь показывала submitted. Передано основному агенту для исправления понятного неизвестного статуса.
- При повторном открытии редактора непрозрачная чёрно-белая PNG закрывала оригинальную фотографию под синим наложением. Точки восстановлены правильно. Передано основному агенту для исправления визуального наложения без изменения геометрии.
- Оба указанных функциональных/визуальных дефекта исправлены основным агентом и повторно проверены на APK +10.
- Небольшой остаток оформления: локальная история эталонных измерений сохраняет отображение точного ISO времени; данные/происхождение не теряются. Зафиксировано отдельно, без незапланированного изменения поведения после финальной сборки.
